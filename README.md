## 这是什么

一个**纯 PowerShell 单文件工具**（外加一个双击入口），用来把 OpenAI **Codex Desktop / ChatGPT 桌面版** 的界面语言设成简体中文。

它**不是**汉化补丁。它不开刀、不替换任何应用文件，只是打开应用**官方自己提供的**语言配置开关 `localeOverride`，指向应用**官方已经装好的**中文资源。

所以：

| 你关心的 | 结果 |
|---|---|
| 需要联网下载语言包吗 | **不需要**，中文资源随应用一起装在本地 |
| 需要 VPN 吗 | **不需要**，全程零网络请求 |
| 需要装 Node.js / Python 吗 | **不需要**，只用 Windows 自带的 PowerShell 5.1 |
| 需要管理员权限吗 | **不需要**，只写你自己的用户目录 |
| 应用商店更新后失效吗 | **不失效**，配置文件不在应用包里 |
| 会被判定为应用被篡改吗 | **不会**，`WindowsApps` 目录一个字节都不碰 |

## 为什么不需要第三方汉化包

GitHub 上流传的第三方汉化包（例如 `codex-zh-CN-v0.1.2` / `v5.5.5`）走的是
**「把 `app.asar` 复制到用户目录 → 二进制打补丁 → 顶替原文件」** 这条路。
在新版应用上，这条路不但没必要，而且是**负优化**：

| 对比项 | 第三方汉化包 | 本项目 |
|---|---|---|
| 原理 | 复制 1.8 GB 应用到 `~/.codex/zh-cn-patched`，改写 `app.asar` | 只写官方支持的配置项 `localeOverride` |
| 依赖 | 必须装 Node.js | 只用系统自带 PowerShell |
| 额外磁盘占用 | **+1.8 GB 副本 + 310 MB 备份** | **0** |
| 商店更新后 | 必然失效，要重新打补丁 | **依然有效** |
| 中文完整度 | 原生菜单 **73 键**（缺 128 键） | 应用自带 **196 键**，一字不缺 |
| 需要 VPN / 联网 | 要从 GitHub 下载 | 完全离线 |
| 风险 | 修改应用文件，可能触发完整性校验 | 应用文件**一个字节都不动** |

**为什么第三方包反而更差**：新版应用的 `app.asar` 里**本来就内置了 64 种语言**，其中
`native-menu-locales/zh-CN.json` 有 **196 个词条**，还带一个 **1.39 MB 的官方前端中文包**
（`webview/assets/zh-CN-*.js`）。而第三方包塞进去的那份只有 73 键——**它会把你原本完整的中文
覆盖成残缺版**（关于对话框、更新确认、浏览器面板菜单等 128 条直接变成英文）。

## 它到底改了什么

**只动你自己用户目录下的 3 个文件 + 1 个目录，应用安装目录全程只读。**

| 文件 | 改动 |
|---|---|
| `%USERPROFILE%\.codex\config.toml` | 在 `[desktop]` 段写入 `localeOverride = "zh-CN"`（改前自动备份） |
| `%USERPROFILE%\.codex\computer-use\config.json` | 同步 `locale` 与两条覆盖层文案（见下） |
| `%USERPROFILE%\.wakecat-i18n.json` | 本工具自己的配置（首次运行后生成） |
| `Codex一键汉化\backups\` | 上面文件的带时间戳备份，每个文件只留**最近 5 份** |

- 若 `%USERPROFILE%\.codex` 不存在（应用装完还没启动过），工具会**自动创建**。
- 若脚本所在目录不可写，备份会自动改到 `%LOCALAPPDATA%\Codex-i18n\backups`，绝不影响汉化本身。
- **`C:\Program Files\WindowsApps\...` 始终只读，从不写入。**

### 关于那两条覆盖层文案

应用内置的 `zh-CN.json` 里**没有** `computerUseOverlay.usingComputer` / `escToCancel` 两个键
（我们把 196 个键逐个展开核对过），所以「ChatGPT 正在使用你的电脑」浮层会回退成英文。
工具会尝试把它们补进 `computer-use/config.json`：

```json
"usingComputer": "ChatGPT 正在使用你的电脑",
"escToCancel":   "按 Esc 取消"
```

> ⚠️ **诚实提醒**：`computer-use/config.json` 是**应用自己托管**的文件。实测它会在应用启动时被重写——
> `strings` 恢复成内置英文默认值，并补上 `accentColor` / `direction` 字段（只有 `locale` 被保留）。
> 所以这一步是**尽力而为**，不保证长期生效。如果覆盖层仍显示英文，那是**应用自身没有翻译这两条文案**，
> 与本工具无关，也**不影响界面主体语言**（菜单、设置、对话框由官方 196 键 + 1.39 MB 前端包决定）。

## 工作原理

### 1. 官方开关 `localeOverride`

Electron 应用的界面语言由 `~/.codex/config.toml` 里的这一段决定：

```toml
[desktop]
localeOverride = "zh-CN"
```

工具做的就是**幂等地**维护这一行：`[desktop]` 段存在就改键，不存在就建段，要还原就删键。
所以它改的是一个**用户配置文件**，应用商店更新应用包时不会受影响。

### 2. 中文资源是官方已经装好的

新版应用包（`app.asar`）里内置：

| 资源 | 内容 |
|---|---|
| `native-menu-locales/` | **64 种**语言的菜单文案，`zh-CN.json` 有 **196 键** |
| `webview/assets/zh-CN-*.js` | 官方前端中文包，**1.39 MB** |

工具会用纯 PowerShell 解析 `app.asar` 的 pickle 头部（**嵌套目录树**，不是斜杠路径），
把这两个资源的**存在性与词条数**读出来做体检——**只读**，不做任何写入。

### 3. 应用定位是四级降级

不匹配版本号，以下四步依次尝试，命中即用：

1. `[7] 设置` 里手动指定的 `appPath`
2. 正在运行的进程（`ChatGPT.exe` / `Codex.exe`）反推安装目录
3. `Get-AppxPackage` 模糊匹配 `OpenAI.*` / `*Codex*` / `*ChatGPT*`
4. 常见目录扫描（`%LOCALAPPDATA%\Programs`、`C:\Program Files\Codex`、桌面、下载目录…）

所以 MSIX 商店版、便携版都能认，换新版本也不怕。

### 4. 副产物清理

第三方汉化包会在用户目录留下这些可再生副本，`[6]` 会列出占用并送进**回收站**：

| 路径 | 典型大小 |
|---|---|
| `%USERPROFILE%\.codex\zh-cn-patched` | ~1.8 GB |
| `%USERPROFILE%\.codex\zh-cn-install-backups` | ~310 MB |
| `%USERPROFILE%\.codex\.zh-cn-backups` | 极小 |
| `%USERPROFILE%\.codex\codex-desktop-path.txt` | 极小 |

## 换台电脑能用吗

**能，这份工具从设计上就不绑机器。** 环境要求与验证结果：

| 依赖项 | 情况 |
|---|---|
| 本机用户名 / 盘符 / 应用版本号 | **未写死**，路径全部来自 `%USERPROFILE%` / `%LOCALAPPDATA%` / `$PSScriptRoot` |
| 应用版本 | 不校验版本号，靠四级降级**自动定位**任意 26.9xx+ 版本 |
| Node.js / Python / 第三方库 | **不需要** |
| 管理员权限 | **不需要** |
| 联网 / VPN | **不需要** |
| 中文字体 | **不需要**（横幅用半角块字符） |
| 操作系统 | Windows 10 / 11（需自带 PowerShell 5.1） |

**唯一可能需要手动介入的情况**：应用装在非常规位置，且既不在运行、又不属于商店包。
此时 `[2] 体检` 会显示「未找到」，用 `[7] 设置` 填一次 `app` 目录（含 `resources\app.asar` 的那一层）即可，
设置会记进 `.wakecat-i18n.json`。

**三个小提示**

- 脚本请放在**本地磁盘**运行，PowerShell 5.1 对 UNC（网络共享）路径支持不佳
- 从下载的 ZIP 解开后，`.cmd` / `.ps1` 的文件名带中文没问题：启动器 `.cmd` 内部是**纯 ASCII**，
  用 `%~dp0` 通配自己找同目录的 `.ps1`，主脚本改名也不会失联
- 语言代码以**目标机器上的应用**为准，`[2]` 会打印语言总数，`[3]` 可列出全部代码

## 命令行用法

所有功能都有对应的非交互模式，方便写进脚本或计划任务：

```powershell
# 体检报告（顺便预览界面）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action report

# 一键汉化（无界面）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action apply -Language zh-CN

# 切换成繁体
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action languages -Language zh-TW

# 还原英文
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action restore

# 清理副产物（-Yes 跳过确认；不带 -Yes 且非交互时只列清单，不会删任何东西）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action clean -Yes

# 网络 / 代理检测
powershell -NoProfile -ExecutionPolicy Bypass -File .\Codex一键汉化.ps1 -Action net
```

`-Action` 可选：`menu`（默认）/ `report` / `check` / `apply` / `restore` / `languages` / `clean` / `net` / `launch`

不带任何参数时进入**常驻交互窗口**（循环菜单 + 状态面板 + 回车返回）。

## 常见问题

**Q：设置了 `zh-CN`，界面还是英文？**
A：完全退出应用再启动。托盘图标右键 → 退出；只点窗口关闭按钮进程还在，配置不会重载。

**Q：`[2] 体检` 显示「官方语言 64 种 · 原生菜单中文 196 键」但还是英文？**
A：检查 `[7] 设置` 里是不是手滑指定了错误的 `appPath`。

**Q：这个版本会不会已经不提供简体中文了？**
A：`[2] 体检` 若显示「简体中文资源：缺失」，就说明确实没有。此时本工具**不会**硬塞一份残缺翻译进去——
那正是第三方包的老毛病。

**Q：会不会影响应用签名 / 被打上篡改标记？**
A：不会。`WindowsApps` 目录一个字节都没动，不存在 asar 完整性熔丝（integrity fuse）问题。

**Q：汉化要下载语言包、要挂 VPN 吗？**
A：都不需要。中文资源随应用安装包一起落在本机，`localeOverride` 只是一个本地配置项。
菜单 `[8]` 的网络检测是另一回事——它只回答「应用的登录/对话功能能不能连上」，
连不上只影响功能，**不影响界面是否中文**。

**Q：想换别的语言？**
A：`[3] 切换界面语言`，64 种任选（日语、韩语、德语……）。

**Q：`config.toml` 被我改坏了怎么办？**
A：每次改动前都会自动备份到 `backups\`（保留最近 5 份），把 `.bak` 改回原名覆盖即可。

## 已知限制

- **覆盖层文案不保证生效**：见上文「关于那两条覆盖层文案」，那是应用自身的未翻译项
- **仅支持 Windows**：脚本是 PowerShell 5.1，依赖 `.cmd` 入口与 Windows 的用户目录结构
- **界面语言 ≠ 功能可用**：能否登录、对话是否流畅由网络决定，与本工具无关
- **不做版本白名单**：只要应用还带 `native-menu-locales`，就能汉化；应用哪天移除中文资源，体检会如实报「缺失」

## 目录结构

```
Codex-zh-cn-tool/
├── Codex一键汉化.cmd     ← 双击这个（启动器，内容纯 ASCII）
├── Codex一键汉化.ps1     ← 主程序（UTF-8 with BOM，单文件，无外部依赖）
├── codex-i18n.cmd        ← 备用入口，作用完全相同（名称全 ASCII，便于命令行调用）
├── README.md             ← 本文件
├── LICENSE               ← MIT
├── .gitignore
├── backups/              ← 运行后生成：config.toml / config.json 的带时间戳备份
└── resources/            ← 运行后可选生成：从本机应用提取的官方中文资源（仅留档，程序不依赖）
```

> 仓库里**不包含** `backups/` 与 `resources/`：前者含本机个人配置，后者是应用自带的官方资源文件。
> 这两项都不影响工具运行。

## 卸载与还原

**不需要卸载程序**，因为它没装任何东西。要还原：

1. 打开工具，按 **`4`** 还原英文设置（会自动摘掉 `localeOverride`）
2. 按 **`6`** 清理副产物（把第三方包留下的 1.8 GB 副本送进回收站）
3. 删掉工具目录，以及 `%USERPROFILE%\.wakecat-i18n.json` 这个配置缓存，就彻底干净了

应用本身**全程未被修改**，所以不存在"还原不干净"的问题。
